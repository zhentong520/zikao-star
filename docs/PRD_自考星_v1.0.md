## 1. 产品概述

### 1.1 一句话定位
**自考星**是一款「报考即生成作战计划」的成人自考本科备考管理 App：用户选择省份 + 主考院校 + 专业后，自动生成完整考纲（全部科目、学分、考核方式）、跟踪每一科的考试状态与成绩、计算整体毕业进度与学位均分，并在考试科目、时间、院校政策发生变动时主动推送提醒。

### 1.2 要解决的真实痛点

| 编号 | 痛点 | 现状（用户真实困境） | 我们的解法 |
|------|------|------------------------|-----------|
| P1 | **信息散落** | 考纲在省考试院官网、科目表在各类机构站、分数线在另一页，看一次要跳 5-8 个网页 | 结构化考纲一键生成，10 秒完成建档 |
| P2 | **进度无感** | 不知道自己还剩几门、考到哪一步、能不能按时毕业 | 首页环形进度 + 学分进度 + 「预计毕业时间」 |
| P3 | **均分焦虑** | 很多人考完才发现学位要求均分 70，前几门考了 60 多分，学位没了 | 实时「学位均分仪表盘」，预测「按当前均分趋势能否拿学位」 |
| P4 | **时间错过** | 报名时间、开考时间、成绩公布时间分散，容易错过一次就等半年 | 三级提醒体系（报名期 / 考前 7 天 / 考前 1 天 / 成绩公布） |
| P5 | **变动踩坑** | 换考纲、课程代码调整、考试时间变动，往往是考完才知道 | 变动监测 + 差异对比高亮 + 强提醒 |
| P6 | **论文迷茫** | 不知道论文什么时候启动、题目怎么选、答辩要求是什么 | 论文看板：方向选择 → 开题 → 撰写 → 查重 → 答辩 → 成绩 |
| P7 | **决策盲目** | 加考几门？哪门先考？英语二什么时候考最省力？ | 考科规划器：给出推荐考科顺序与最短毕业路径 |

### 1.3 产品目标（V1.0）

**北极星指标**：近 30 天内完成一次「学习闭环」的用户数（学习闭环 = 打开 App 查看进度 + 查看 ≥1 门科目资讯 + 记录/更新 1 次学习状态）

| 目标 | 指标 | V1.0 目标值 |
|------|------|------------|
| G1 建档转化 | 新用户完成专业选择建档率 | ≥ 70% |
| G2 留存 | 次日留存 / 7 日留存 | 40% / 18% |
| G3 提醒有效性 | 提醒点击率（进入科目详情） | ≥ 25% |
| G4 变动预警价值 | 政策变动消息的「已读 + 采纳行动」率 | ≥ 30% |
| G5 口碑 | 应用商店评分 | ≥ 4.6 |

### 1.4 非目标（V1.0 明确不做）
- ❌ 不做付费课程售卖（避免信任污染，V2 考虑与机构合作分成）
- ❌ 不做真题题库与在线刷题（V2.0 规划，V1 先接第三方内容跳转）
- ❌ 不做代报名、代缴费等涉及官方渠道的服务
- ❌ 不承诺「包过」「保学位」等违反广告法的表述

## 2. 目标用户

### 2.1 用户画像

**主 Persona：小鹿（26 岁，广州）**
- 身份：广州某公司行政专员，本科为专科毕业
- 目的：2026 年 9 月报考华南师范大学 080901 计算机科学与技术（专升本），目标拿学位
- 现状：已通过 03708 中国近现代史纲要（82 分）、15043 中国近现代史纲要（未考）
- 痛点：不知道该先考哪门、担心英语二难度、听说平均分要 70 很慌
- 设备：iPhone / 小米，碎片时间刷手机
- 期望：每天 30 秒看完「我今天该干嘛」

**次 Persona：老陈（38 岁，佛山）**
- 身份：制造业车间主管，在职备考
- 特点：时间不固定，需要清晰的日程和倒计时；对价格敏感，倾向免费工具
- 期望：报名节点绝不漏，考完立刻能录成绩

**次 Persona：小艾（21 岁，大学生）**
- 身份：专科在读，想提前规划自考
- 特点：怕选错专业、喜欢分享攻略、社交分享意愿强
- 期望：能对比不同专业的难度和毕业时长

### 2.2 用户场景（JTBD）
1. **首次使用**：我要知道这个专业要考哪些科目、总共多少学分 → 3 分钟内看到完整考纲
2. **日常查看**：今天有什么考试要准备 → 首页 30 秒速览
3. **考后记录**：考完了，记一下分数 → 3 次点击录入成功
4. **政策变动**：听说广东换考纲了 → App 主动告诉我哪几门变了
5. **论文阶段**：快毕业了，论文该找什么方向 → 论文看板给方向库

> ⚠️ **产品必须处理的现实约束**：
> 1. **课程组问题**：广东省 080901 采用「专业课程组」形式，主考院校包括华南理工大学、华南师范大学、深圳大学、广东外语外贸大学、广东财经大学等，同一专业代码下不同院校课程组略有差异。因此选择页必须精确到「院校 + 课程组」，不能只选专业代码。
> 2. **新旧计划并存**：2026 年起执行新计划，旧计划考生有过渡期与课程顶替表。产品需同时保留两版考纲并标注「你的考纲版本」。
> 3. **数据时效性**：考纲数据必须标注 `lastVerifiedAt`，超过 180 天未核验要在选择页提示「本专业数据可能已变动，请以省考试院公告为准」。

### 模块 B：首页 · 报考总览

首页是最高频页面，设计目标：**30 秒掌握全局**。

| 需求 ID | 区块 | 内容 |
|---------|------|------|
| B-01 | 顶部用户卡 | 头像、昵称、省/校/专业摘要、当前考期倒计时 |
| B-02 | 总进度环 | 环形进度展示「毕业进度 = 已通过学分 / 总学分」，中心显示百分比 + 「已过 X / 16 门」 |
| B-03 | 关键指标四宫格 | 已通过学分 / 平均分（加权 & 算术）/ 距离预计毕业 / 学位均分达标状态 |
| B-04 | 最近考试倒计时 | 下一场考试：日期倒计时（如「还有 23 天」）、科目、考点城市、考场信息（若可获取） |
| B-05 | 待考科目横向卡片 | 展示待考科目 chip 列表，可横滑，状态：待考/报名中/已报名/备考中/已考过/未通过 |
| B-06 | 今日资讯（TOP 3） | 抓取到的本专业/本院校最新资讯，点击进入资讯详情 |
| B-07 | 变动预警横幅 | 若有考纲/时间变动，横幅置顶高亮「你的专业有 3 项变动」 |
| B-08 | 快捷操作 | 录成绩 / 选考科目 / 看论文进度 / 加日历 |
| B-09 | 鼓励卡（甜系特色） | 根据进度生成一句暖心文案（"你已经超过 68% 的考友啦 🌸"） |

**B-02 进度算法**（明确定义，避免研发理解偏差）：

```
毕业进度 = Σ(已通过课程学分) / Σ(全部必考课程学分) × 100%
  · 成绩 ≥ 60 分 → 该课程学分计入
  · 成绩 < 60 分 → 不计入，科目状态标记「待补考」
  · 实践考核 / 毕业论文：合格即计入，论文不计学分但计入「环节完成度」
  · 加考课 / 顶替课：按用户实际勾选的计划学分参与计算
```

```
学位均分 = Σ(课程成绩 × 课程学分) / Σ(计入均分的课程学分)
  · 免修 / 免考课程不计入均分
  · 同一课程多次合格成绩取最高分
  · 非百分制（优秀/良好/中等/及格）折算：优秀 95、良好 85、中等 75、及格 65
  · 毕业论文成绩计入均分（华师规定）
  · 实践考核成绩是否计入 → 以各院校细则为准，页面给出提示
```

### 模块 D：资讯抓取与变动监测

这是产品的**核心壁垒**，也是技术难点，需要详细设计。

| 需求 ID | 功能 | 优先级 | 说明 |
|---------|------|--------|------|
| D-01 | 数据源列表 | P0 | 见 3.1 节数据源矩阵 |
| D-02 | 定时抓取 | P0 | 政策类每日抓取；考纲类每周；考试安排在公告发布窗口期每小时 |
| D-03 | 变动检测引擎 | P0 | 对抓取内容做结构化 Diff，与用户报考数据比对 |
| D-04 | 变动强提醒 | P0 | 一旦与用户相关的科目/时间/政策变动，App 内横幅 + Push，必须用户确认「已知晓」 |
| D-05 | 科目相关性排序 | P0 | 资讯与科目的相关度打分，详情页只展示 TOP3 高相关资讯 |

#### 3.2 变动检测规则（Diff Engine）

```python
# 伪代码：变动检测
def detect_changes(old_plan, new_plan, user_profile):
    changes = []
    # 1. 课程新增 / 删除
    changes += diff_course_set(old_plan, new_plan)
    # 2. 学分变更
    for c in intersect_by_code(old_plan, new_plan):
        if c.old_credits != c.new_credits:
            changes.append(Change(type="CREDIT_CHANGED", course=c, old=c.old_credits, new=c.new_credits))
    # 3. 考核方式变更（笔试 ↔ 实践）
    # 4. 考试时间变动 / 停考 / 缓考
    changes += diff_exam_schedule(user_profile.enrolled_courses, new_schedule)
    # 5. 学位政策变更（均分要求、论文要求、外语要求、申请窗口）
    changes += diff_degree_policy(old_policy, new_policy)
    # 6. 顶替规则变更
    # 风险分级
    for ch in changes:
        ch.risk = compute_risk(ch, user_profile)  # HIGH 立即 Push；MEDIUM 首页横幅；LOW 资讯列表
    return changes
```

**风险分级规则**：
- 🔴 HIGH：已报考科目停考/时间调整/学分变更 → 立即 Push + 首页红条 + 要求确认
- 🟡 MEDIUM：新增必考课/学位政策变化/报名时间变化 → 首页横幅 + 资讯置顶
- 🟢 LOW：一般政策解读/经验帖 → 仅资讯列表

## 6. 技术架构建议

| 层 | 选型 | 说明 |
|----|------|------|
| 前端 | Flutter / React Native | 一套代码双端；甜系 UI 组件库自研（基于 Design Token） |

| 爬虫 | Python Scrapy + Playwright + RSSHub | 定时任务用 APScheduler / Airflow |
| 数据库 | MySQL（业务）+ Redis（缓存/限流）+ MongoDB（资讯原文快照） | 资讯全文可用 ES 检索 |
| 推送 | 极光 / 友盟 / 华为+小米+APNs 通道 | 变动提醒走高优通道 |
| 通知渠道 | 微信服务号模板消息 | V1.1 接入 |
| 定时任务 | 统一调度中心 | 政策抓取 / 考试安排抓取 / 提醒派发 |
| AI 能力 | 摘要生成、资讯分类、相关度打分、题目推荐 | 可用大模型 API |

**关键技术难点**：
1. **考纲结构化**：官网考纲多为 PDF/图片/HTML 表格，需要「规则模板 + 人工核验」双轨。V1.0 建议：**先人工整理 30 个热门专业入库**，爬虫只做「变动检测」，不做全自动解析。
2. **变动检测精度**：避免误报。策略——同一条目连续 2 次抓取结果一致才确认变动；变动内容进入人工审核队列，审核后才推送。
3. **相关度排序**：资讯-科目关联采用「课程代码/名称精确匹配(权重 0.6) + 关键词 TF-IDF(0.3) + 时间衰减(0.1)」。

- 字号：标题 20/17、正文 15、辅助 13、成绩大数字 40/600

### 8.5 插画与图标
- 插画风格：扁平 + 圆角 + 柔和渐变 + 小元素点缀（星星、云朵、书页、花瓣）
- 状态插画：待考（懒羊羊式打盹猫）、备考中（加油小人）、已通过（戴学士帽小人）、论文（写字的小人）
- 图标：圆头线性图标，2px 描边，颜色跟随主色
- 鼓励文案风格：温柔不油腻，「今天也是被学习 bless 的一天 🌷」

### 8.6 特色组件
1. **进度环**：中心显示百分比，下方小字「已过 6/16 门 · 还需 45 学分」，环上用小圆点标记不及格科目
2. **科目状态胶囊**：`待考`（奶油灰）/ `备考中`（蜜桃粉，脉冲呼吸动画）/ `已考待出分`（暖阳黄，闪烁）/ `已通过 78`（抹茶绿）
3. **倒计时卡片**：数字用超大字号 + 渐变底 + 轻量 confetti 装饰（考试临近时）
4. **资讯 TOP3 卡片**：左上角「相关度」标签（高相关=橘红描边），底部来源图标 + 时间
5. **均分仪表盘**：半圆表盘，70 分处画一条橘红目标线，指针指向当前均分，缺口用斜纹填充
6. **鼓励卡**：右下角小太阳/月亮插画，随时间变化文案

## 11. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| **数据不准**（考纲录入错误） | 高：误导用户 | 标注核验时间 + 用户纠错通道 + 人工双审 + 变动检测兜底 |
| **政策变动爬取不及时** | 中 | 变动提醒同时走「订阅院校官方号」+ 社区信息源双通道 |
| **院校差异导致学位规则复杂** | 中 | 规则引擎 + 院校规则库，V1 先做广东 6 所主考院校 |

| **小程序/App 双端成本** | 中 | V1.0 仅 App，V2 补小程序（提醒触达） |
| **进度算法引发争议** | 低 | 算法规则在设置页公开说明，口径透明 |

- **考试频次**：广东自考一年 **3 次**（1 月、4 月、10 月），报名时间约在考前 2-3 个月（11 月 / 2 月 / 8 月）

### 12.2 华南师范大学 学士学位授予条件（教学〔2025〕9 号）
1. 在读期间该专业**所有课程平均成绩 ≥ 70 分**
2. 在学习年限内通过学位外语考试（满足其一）：
   - 全国大学英语四级/六级 ≥ 425 分
   - 全国英语等级考试（PETS）三级笔试合格
   - 广东省成人高等教育学士学位外国语水平统一考试合格
   - **自考英语（二）或英语（专升本）统考成绩合格** ← 对自考考生最省事的路径
   - 网络教育公共基础课《大学英语》B/C ≥ 80 分
   - 华师自行组织的学位外语考试合格
3. **2025 年 9 月之后获颁毕业证书者，毕业论文/设计须通过答辩且总评 ≥ 70 分**
4. 申请时限：不得晚于毕业证书签发时间 **6 个月**
5. 申报系统：`https://hnsfdx.jxjy.chaoxing.com/login`，一年两次（4 月 / 10 月）
6. 提交材料：论文 Word（含封面/目录/正文）、开题报告 Word、查重报告 PDF、学位外语成绩证明、毕业证书、身份证扫描件
7. **平均分计算规则**：
   - 免修/免考课程不计入
   - 补考及格按 60 分计
   - 含加考、选考课程及毕业论文成绩
   - 同一课程多次合格取最高分
   - 非百分制折算：优秀 95 / 良好 85 / 中等 75 / 及格 65
   - 加考课程成绩是否计入 → 以各校细则为准（部分院校明确不计入）

## 13. 竞品参考与差异化

| 产品 | 优势 | 不足 | 我们的差异化 |
|------|------|------|-----------|
| 传统机构 App（大牛/尚德等） | 课程体系成熟、有题库 | 强销售导向、考务信息杂、广告多 | 我们做**纯工具 + 中立信息中枢** |
| 自考网类站点 | 考纲信息全 | 无个人进度、移动端体验差、无法提醒 | 结构化数据 + 个性化进度 + 主动提醒 |
| 通用日历/待办 App | 灵活 | 不懂自考规则，无法自动生成考纲 | 垂直领域模型，零配置建档 |
| 小红书/知乎 | 经验真实 | 信息碎片化、真假难辨、无法追踪时间线 | 结构化 + 可溯源 + 时间轴 |

**一句话差异化**：**别人帮你卖课，我们帮你管进度。**
