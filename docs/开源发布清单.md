## ✅ 发布前必做

### 1. 确认个人数据未被提交

```bash
# 应该只看到源码，不应有 data/
git status --short | grep data/

# 检查示例库是空的
node -e "const{DatabaseSync}=require('node:sqlite');const d=new DatabaseSync('data-sample/zikao.db');console.log('成绩条数:',d.prepare('SELECT COUNT(*) c FROM score_record').get().c)"
# 期望输出：成绩条数: 0
```

`.gitignore` 已挡住的：`data/`（你的真实成绩）、`node_modules/`、`android/app/build/`、`*.apk`、`web/shared/`（自动生成）

### 2. 替换仓库地址占位符

README 和 package.json 里有 `<你的用户名>`，全局替换：

```bash
# 先在 GitHub 上创建仓库，记下用户名
grep -rn "你的用户名" README.md package.json
# 手动改成你的实际用户名
```

### 3. 确认包名不含个人信息

包名已改为中性的 `com.zikaostar.app`。如果你想改成自己的：

```bash
grep -rn "com.zikaostar.app" capacitor.config.json android/app/build.gradle
```

## 📱 发布 APK（可选，让别人不用自己编译）

### 方式 A：传 Releases（手动）

1. 到 GitHub 仓库 → 右侧 **Releases** → **Create a new release**
2. Tag 选 `v1.0.0`
3. 把 `zikao.apk` 拖进去上传
4. 标题写 `v1.0.0`，说明里放一段简介

### 方式 B：自动构建（推荐）

仓库里已配好 `.github/workflows/build-apk.yml`：

1. 推代码时把 `workflows/build-apk.yml` 里的 apk 路径确认正确
2. 仓库 **Settings → Actions → General** → 勾选 "Allow all actions"
3. 之后每次打 tag 会自动构建并上传

## 🔐 安全提醒

推之前再扫一遍：

```bash
# 有没有意外的密钥
git ls-files | while read f; do
  [ -f "$f" ] && grep -lE "api[_-]?key|secret|token|password" "$f" 2>/dev/null
done

# 有没有你的本机绝对路径
git ls-files | while read f; do
  [ -f "$f" ] && grep -lE "E:/workbuddy|C:/Users/Administrator" "$f" 2>/dev/null
done
```

两个命令都应该是空输出。如果有输出，处理掉再推。
